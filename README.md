# श्री बालाजी कृपा (Balaji Ki Kripa) - 15-Min Quick Devotional Store 🪔

> **15-Minute Instant Devotional & Temple Prasad Delivery Store (Swiggy / Zepto Style)** with multi-language support (English, Hindi, Sanskrit, Gujarati, Telugu, Tamil, Bengali), interactive quick checkout, dynamic payment gateway, live order tracking, and a comprehensive real-time Admin Command Center.

---

## 📱 Features

1. **Quick-Commerce Mobile-First UI (Swiggy / Zepto Style)**:
   - 15-Minute delivery promise banner with live address selection.
   - Category pill slider (Sacred Prasad, Pure Brass Idols, Puja Samagri, Rudraksha Mala, Gada & Kawach, Religious Books).
   - Dynamic product cards with quantity stepper `[-] [Qty] [+]`, MRP discounts, and low-stock indicators.
   - Floating sticky cart bar that triggers when items are added.
2. **Instant Multi-Language Switcher (7 Languages)**:
   - English, हिन्दी (Hindi), संस्कृतम् (Sanskrit), ગુજરાતી (Gujarati), తెలుగు (Telugu), தமிழ் (Tamil), বাংলা (Bengali).
3. **Interactive Devotional Cart & Checkout**:
   - Free Temple Sankalp & Gotra input for puja blessings.
   - Coupon codes (`BALAJI108` for 10% off, `PRASAD50`).
   - Optional Temple Bhandara & Gaushala Seva donation chips (₹11, ₹21, ₹51, ₹108).
   - Clear bill summary with item totals, delivery fees, discounts, and total to pay.
4. **Complete Payment Gateway Simulation**:
   - UPI (Google Pay, PhonePe, Paytm).
   - Dynamic QR Code generator with countdown timer.
   - Debit / Credit Cards & Cash on Delivery (COD).
5. **Live Order Tracking**:
   - Real-time animated timeline: `Placed` ➔ `Blessed` ➔ `Out for Delivery` ➔ `Delivered`.
6. **🛡️ Admin Command Center**:
   - Real-time sales revenue, total orders, and low-stock alerts.
   - Live order status manager (change order status to Preparing, Dispatched, Delivered).
   - Live inventory management: edit prices and stock quantities directly or add new items.
7. **PWA (Progressive Web App)**:
   - Installable on iOS / Android with offline cache support.
